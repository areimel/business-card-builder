<CaseStudy index="01" kicker="Incident Response" title="SendGrid API Key Compromise" stack="SendGrid, SSH, WP-CLI, Python, WordPress">

<StatRow>
<Stat value="~300" label="Sites re-keyed" />
<Stat value="~8 hrs" label="To full restore" />
<Stat value="1 → All" label="Leaked key, every client" />
</StatRow>

<Challenge>

An email alert flagged a SendGrid problem, with nothing to show it affected the whole fleet. An API key had leaked from an old, unmaintained client site that was hacked, and SendGrid suspended the shared account that sent email for every client website.

</Challenge>

<Action>

- Recognized that the outage affected the entire fleet and took the lead on the response.
- Traced the leak to the compromised site and contained it.
- Built SSH, WP-CLI, and Python automation to roll out new API keys across approximately 300 WordPress sites, working late into the night.

</Action>

<Result>

Restored email for every client in about 8 hours, the same day.

</Result>

</CaseStudy>
